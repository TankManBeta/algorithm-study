# 🧠 Algorithm Study
This repository contains implementations, notes, and experiments with machine learning and deep learning algorithms, primarily focusing on architectures such as Transformers and their variants.
It serves as a record of my learning progress, implementation insights, and continuous exploration of modern algorithmic ideas in AI.

# 🚀 Overview
The goal of this project is to understand and re-implement key algorithms behind modern neural network architectures.
Each update may include:
- Core implementations of Transformer modules
- Attention mechanisms and feed-forward designs
- Training experiments and ablation studies
- Implementation notes, comments, and optimization ideas

# 📂 Topics Covered
- Transformer and Self-Attention
- Multi-Head Attention
- Positional Encoding
- Feed-Forward Networks (MLP blocks)
- Normalization and Residual Connections
- Vision Transformer (ViT) and variants
- Other architectures and algorithmic explorations in ML
